# Public Specifications

This directory is reserved for reviewed technical specifications.

Candidate subjects include:

- Evidence record contracts
- Cryptographic hash-world identification
- Merkle commitment semantics
- Proof and verification interfaces
- Evidence provenance and custody
- Independent verification requirements

No normative technical specification is published in this
initial version.

Internal specifications are not automatically public
standards or externally approved contracts.

Future documents must identify version, status, authority,
scope, limitations, and change history.
