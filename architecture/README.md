# FidoMota Architecture

FidoMota is developing an evidence-to-verification pipeline.

Conceptual flow:

1. Source observations
2. Authentication and trust admission
3. Native evidence recording
4. Merkle root construction
5. Batch assembly and registry indexing
6. FAST and zero-knowledge proof paths
7. Independent verification

These describe intended system responsibilities, not a claim
that all stages have completed one independently verified E2E run.

Architecture documentation will distinguish existing implementation,
observed runtime evidence, and planned interfaces.

No private service topology, operational credentials, or
internal infrastructure details are published here.
